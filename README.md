# Overstack for Horizon

Overstack raises the default stack size of stackable items to 999. Items that normally stack to one remain non-stackable.

This is an independent native mod for Horizon Rust Edition, inspired by the behavior of the Overstack mod for Minecraft Java Edition. It is not affiliated with or a port of that project.

## Install

Download `overstack-1.0.0.hnmod` from the Releases page and install it with Horizon Launcher. The launcher builds native mods into the selected game version.

## Compatibility

- Minecraft version: 26.3
- Built against Horizon commit `9f42064c11efe7ef3e5ed2baad7ddc2a3b36eea0`
- Maximum stack size: 999

This native mod runs with the same computer permissions as Horizon. Only install it if you trust the source.
